Repozitorijum sa materijalima i rešenjima zadataka iz vežbi. Obuhvata rad u Python-u, analizu i obradu podataka pomoću Pandas biblioteke, vizualizaciju podataka uz Matplotlib, kao i web scraping korišćenjem Selenium i Beautiful Soup biblioteka.

## Tehnologije

* Python
* Pandas
* Matplotlib
* Selenium
* Beautiful Soup
